# BeCOOLforClimate
a prompt-based climate conversation tool for universal use

---

## 🎨 About the Project
**COOL** is a four‑point prompt sequence that helps people navigate climate conversations with confidence, clarity, and critical thinking.

**C-O-O-L** stands for: **Clarify** your actions, **Observe** your impacts, **Own** your responsibility, **Live** your values 

It’s a discussion guide designed to help both individuals and organizations communicate clearly, make meaningful choices, and push for the systemic changes needed to protect and beautify our home planet.

* **Creator:** Heather Succio
* **Status:** Open Source / Creative Commons
